Data Structures in C++
This repository provides simple and clean implementations of common data structures and sorting algorithms using C++.

📁 Folder Structure
LinkedList by c++
Contains:

Singly Linked List
Doubly Linked List
Circular Linked List
Binary Search Tree (BST)
Sorting by c++
Contains:

Bubble Sort
Insertion Sort
Selection Sort
Merge Sort
Quick Sort
🎯 Purpose
This project is designed for students and learners who want to:

Understand how fundamental data structures work.
Practice implementing sorting algorithms in C++.
Enhance their knowledge in data structures and algorithm analysis.
🛠️ Technologies Used
Language: C++
Compiler: g++, MSVC, or any standard C++ compiler
🚀 Getting Started
Clone the repository:
git clone https://github.com/your-username/data-structures-cpp.git
Navigate to the project directory:

bash Copy Edit cd data-structures-cpp Compile any .cpp file:

bash Copy Edit g++ LinkedList\linked_list.cpp -o linked_list ./linked_list Replace linked_list.cpp with the desired file you want to compile.
